# Как сделать, чтобы книги видели все устройства (бесплатно, без сервера)

Сайт живёт на GitHub Pages, а Pages умеет отдавать **только файлы репозитория** —
базы данных там нет. Поэтому книги храним… в самом репозитории:

- файл книги кладётся в папку `library/…`;
- список книг — в `library/index.json`;
- сайт на Pages сам подхватывает этот список — **все устройства увидят книги
  через 1–2 минуты после push** (столько GitHub пересобирает Pages).
- Добавлять/удалять книги может только тот, у кого есть право push в репозиторий
  (то есть только владелец). Остальные — читают и скачивают.

## Что нужно один раз

1. Установить [Node.js](https://nodejs.org) (любая версия 18+).
2. Склонировать репозиторий и открыть его в терминале:
   ```bash
   git clone https://github.com/Yangisss/books.git
   cd books
   ```
3. Настроить доступ к GitHub (появится окно браузера для подтверждения):
   ```bash
   gh auth login
   ```

## Добавить книгу

```bash
node tools/publish-library.mjs add 11a math "Підручник Алгебра 11 клас.pdf" --git
```

- первое слово после `add` — класс (`11a`), второе — **id предмета** с сайта:
  `math`, `physics`, `chemistry`, `biology`, `astronomy`, `ukr-lang`, `ukr-lit`,
  `english`, `history-ua`, `world-history`, `informatics`, `world-lit`, `art`, `geography`;
- можно несколько файлов сразу: `… add 11a math a.pdf b.pdf c.pdf --git`;
- `--git` — скрипт сам сделает commit и push. Без него можно проверить результат
  и запушить вручную: `git add library && git commit -m "Books" && git push`.

Через минуту откройте сайт с любого устройства — книга на полке предмета.

## Посмотреть, удалить

```bash
node tools/publish-library.mjs list          # все книги с id
node tools/publish-library.mjs rm <id> --git # удалить книгу
```

## Ограничения (это нормально для Pages)

- до 50 МБ на файл (больше — GitHub ругается; для сканов учебника хватает);
- суммарно старайтесь держать `library/` в пределах ~300 МБ;
- если кто-то открыл сайт ровно во время обновления — обновите страницу.

## Альтернатива с «полноценной базой»

Если хочется загружать книги прямо с телефона через сайт — нужен сервер
(`node server.mjs`) на постоянном хостинге с диском. Инструкция в `DEPLOY.md`.
На бесплатных тарифах без постоянного диска книги пропадают после сна сервера,
поэтому для школы вариант с репозиторием выше — самый надёжный и бесплатный.
